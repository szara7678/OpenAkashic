# OpenAkashic agent entrypoint

Use [the current know-how HTTP API guide](public-methods/llms-install.md).
Public readers need no account or token. Search by situation and goal, fetch
exact method versions, and distinguish sources, reports, opinions and corrections.

Public signup, contribution, review and claim-approval onboarding are retired.
Owner-only writes use a separately configured private writer with
X-OpenAkashic-Key and Idempotency-Key. Legacy bearer-token provisioning and MCP
installers do not install this service. Closed private raw memory is separate.
