# 실행 과제 비교 2026-11-15

네 합성 과제를 두 번씩 반복해 일반 웹 검색과 OpenAkashic 우선을 비교한 16회 기록입니다. 같은 `gpt-6.1-sol`, medium, native CLI와 격리 환경을 사용했습니다. 전체 성공은 **OA 8/8, Web 5/8**이며, 코드 검사는 **16/16** 통과했습니다. Web의 세 로컬 예산 종료는 실패로 보존했습니다.

양쪽이 모두 완전 성공한 **같은 5/8짝**에서 제공자 총 토큰 합계는 OA가 **14.26% 적었고**, 시간 합계는 **0.535% 짧아 사실상 비슷했습니다**. 시간의 기하평균 비율은 0.9923이며, 기술적 부트스트랩 95% 구간은 0.8648–1.1528로 1을 포함합니다. 명확한 속도 향상이나 일반적인 비용 절감은 입증하지 못했습니다. 숫자가 작은 쪽이라는 이진 조건과 실질적인 개선을 구분합니다.

실패를 포함한 전체 제공자 총 토큰은 **2,990,143**입니다. OA 1,379,458, Web 1,610,685입니다. 입력 2,899,810에는 캐시 입력 2,269,696이 이미 포함돼 있으며 여기에 출력 90,333을 더한 값이 총 토큰입니다. 캐시를 중복 합산하지 않습니다. 실제 요금, 청구서나 현금 절감은 측정하지 않았습니다.

두 평가자가 익명 패킷을 각각 검토했습니다. 검색과 검사가 섞인 명령을 패킷에서 제외하면서 빠진 A09/A13의 검증 출력은 부모 검토자가 원본을 대조해 보충 판정했습니다. 두 원래 검토 기록, 보충 근거와 최종 조정을 함께 보존합니다. 출처와 문체에 검색 조건의 단서가 남을 수 있어 완전한 블라인딩을 보장하지 않습니다.

첫 코호트는 실제 과제 본문 대신 일반 지침이 OA 질의로 들어가 2/16회 뒤 중단했습니다. 이 기록과 미실행 14회를 합산하지 않습니다. 별도 v2는 과제 본문을 양쪽 초기 문맥에 동일하게 넣었습니다. v2의 여덟 번째 실행에서 로컬 예산 실패가 발생한 뒤, 이미 예약된 나머지 여덟 실행을 모두 마치도록 제어기의 중단 정책만 수정했습니다. 모델, 과제, 프롬프트, 검색 코드와 각 실행의 한도는 바꾸지 않았고 실패를 재시도하지 않았습니다. 첫 짝이 이미 노출됐고 제어 정책도 중간에 바뀐 탐색적 코호트입니다.

실제 중복 본문 캐시 적중은 **0회**입니다. 별도 무모델 재생에서 같은 SQLite v3 GET을 같은 JSON 직렬화로 비교했을 때 18,851바이트가 12,475바이트 영수증으로 줄고 최신 피드백은 유지됐습니다. 이 동작 확인을 실제 토큰이나 시간 절감에 귀속하지 않습니다. 방법 적용은 OA 여섯 실행에서 일곱 방법 적용으로 대조했으며 HTTP 두 실행의 검색 미회수는 적용으로 바꾸지 않았습니다. owner 피드백은 정확한 버전과 본문 해시를 묶은 제안이며 API 쓰기 영수증이 아닙니다.

내용:

- `metrics.json`: 16회 전부와 고정된 5짝, 불확실성, 이전 실패 및 제어 정책 변경.
- `grades/`, `grades.json`, `provenance/parent-verification-supplement.json`: 두 독립 검토와 부모 조정.
- `tasks/`, `checker.py`, `artifacts/`: 합성 과제, 고정 검사와 실제 코드/README.
- `application-review.json`, `proposed-owner-feedback.json`: 본문 열람, README 귀속과 구체적 코드 단계의 대조 및 제한된 목표의 피드백 제안.
- `protocol/`, `provenance/`, `MANIFEST.json`: 조건과 해시. 응답 ID는 해시만 공개합니다.

과제와 검사, 산출물의 기능 검사는 pandas 2.3.3이 있는 Python 3.12 격리 컨테이너에서 다시 실행할 수 있습니다. 예를 들어 준비한 검사 이미지에서 다음을 실행합니다.

```sh
docker run --rm --network none --read-only --user 65534:65534 \
  --cap-drop ALL --security-opt no-new-privileges \
  --memory 384m --cpus 1 --pids-limit 64 --tmpfs /tmp:rw,size=64m \
  -v "$PWD/checker.py:/checker.py:ro" \
  -v "$PWD/artifacts/probe-routing-review-r1-oa:/candidate:ro" \
  YOUR_OFFLINE_CHECKER_IMAGE python /checker.py probe-routing-review /candidate
```

이는 공개 산출물의 오프라인 기능 재검사입니다. 원래 에이전트 실험 전체를 바로 재현하는 묶음은 아닙니다. live 제공자/브로커, 원시 trace와 시스템 프롬프트, 인증/환경 정보, 현재 DB와 인덱스, 캐시 파일과 원출처 본문 전체는 제외했습니다. 요금이나 운영 성과는 이 묶음으로 검증할 수 없습니다. 원래 이미지의 바이트가 같은 환경을 재구성했다고 주장하지 않습니다.
