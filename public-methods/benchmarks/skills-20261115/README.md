# 공개 스킬 선택 비교: 2026-11-15

같은 공개 원본 스킬 6개를 사용하는 두 경로를 세 합성 산출물 과제에서 두 번씩 비교했습니다. 직접 경로는 고정된 이름·설명 카탈로그와 원본 폴더를 점진적으로 읽는 오프라인 기준선입니다. 실제 skills.sh 클라우드 검색 성능을 측정하지 않았습니다. OA는 같은 원본에서 정리한 방법 10개를 추가로 검색합니다. 모델은 양쪽 모두 gpt-6.1-sol, medium이며 새 HOME, 실행 도구와 격리 한도가 같습니다.

부모 검토자가 승인한 엄격한 전체 성공은 **직접 경로 2/6, OA 2/6**입니다. 공동 완전 성공은 분석 과제의 같은 두 짝뿐입니다. 그 두 짝에서 제공자 총 토큰은 OA 292,155, 직접 경로 269,420으로 **OA가 8.44% 더 많았습니다**. 경과 시간은 354.673초와 367.410초로 OA가 3.47% 짧았지만, 사전 기준인 토큰 15% 감소와 시간 10% 감소를 충족하지 못했습니다. 두 짝의 보수적 품질 평균은 각각 14/16이며 반복별 차이는 +1, −1이었습니다. 디자인·문서에는 공동 완전 성공 짝이 없어 세 분야 품질 유지 기준도 충족하지 못했습니다.

실패를 포함한 12회 전체는 직접 경로 **742,703토큰·956.738초**, OA **816,822토큰·1,015.863초**입니다. 총 제공자 토큰은 캐시 입력을 포함한 입력과 출력을 합한 값이며 청구 금액이 아닙니다. 준비, 수집, 편집·방법 정리와 검토 비용은 별도 미확인 값입니다.

실제 OA 파생 방법 적용은 **0회**입니다. 여섯 OA 실행 중 두 실행에는 PDF 방법이 완전 전달됐으나 웹·분석 과제에 부적합해 적용되지 않았고, 네 실행은 빈 결과였습니다. 이후 원본 스킬로 전환한 산출물의 성공을 OA 방법 실행 성과로 기록하지 않습니다. 원문 전달은 주의 깊게 읽었거나 시각 도구를 실제로 보았다는 증거가 아닙니다. 시각적 주의 여부는 독립적으로 확인하지 못했습니다.

## 보존한 실패와 평가 한계

첫 직접 디자인 실행의 로컬 예산 종료는 재시도하지 않았습니다. 첫 실행 뒤 Chromium 프로필 권한 때문에 원래 검사 복사가 중단되어, 모든 행에 UID 안전 복사와 동일한 고정 검사를 적용했습니다. 원본 바이트, 시간·추적 해시를 확인했고 브라우저 프로필만 제외했습니다. 후보 실행이나 기준은 바꾸지 않았습니다.

문서 검사는 날짜를 ISO 문자열로 찾는 고정 조건이 있어 같은 날짜의 영문 표기를 인정하지 못합니다. 디자인의 Service 접두 라벨은 Services 컨테이너와 충돌할 수 있습니다. 이 제한과 실패 결과를 그대로 남겼으며 사후에 검사를 고치거나 성공으로 재분류하지 않았습니다. 검토용 필터 화면만 정확한 combobox 선택자로 보충했고 원래 실패와 렌더 보정 근거를 분리했습니다.

두 독립 평가자의 항목별 낮은 점수를 합산했고 부모 점수 덮어쓰기는 없었습니다. 원본 검토 점수와 부모 판정은 metrics.json과 grades/에 있습니다. 검색과 검사가 섞인 명령에서는 출처 정체성만 정확한 승인 범위로 가리고 실제 코드·검사·출력은 보존했습니다. 문체와 기법에 단서가 남을 수 있어 완전한 블라인딩을 보장하지 않습니다.

## 원본 바이트와 재검사

artifacts/는 읽기 전용 원본을 UID 안전 복사한 자료에서 선택한 공개 산출물·생성기·검사 코드·QA·README입니다. 각 파일은 원본 및 복사 영수증 해시와 같습니다. 네 summary.csv의 CRLF를 그대로 보존했습니다. 익명 검토 패킷의 CSV는 LF로 투영됐으므로 패킷 해시를 원본 바이트 해시로 사용하지 않습니다. 차이는 artifact-provenance.json에 기록했습니다. .gitattributes가 산출물의 Git 줄바꿈 변환을 막습니다.

~~~sh
python3 verify_export.py
python3 verify_export.py --replay-checks --image YOUR_PREPARED_OFFLINE_IMAGE
~~~

재검사는 네트워크가 없는 읽기 전용 Docker 컨테이너 안에서만 후보 HTML/코드를 실행합니다. 원래 실패를 기대 결과로 대조하며 보관된 결과를 덮어쓰지 않습니다. environment/는 공개 의존성으로 재검사 이미지를 준비하는 예시입니다. 설치에는 네트워크가 필요할 수 있고 재빌드 이미지가 원래 이미지 바이트와 같다고 주장하지 않습니다. 원본 스킬·연결 문서·외부 의존성 전체가 실행 가능한 닫힌 환경이라고 주장하지도 않습니다.

이 묶음에는 인증, 제공자 원시 trace·시스템 프롬프트, 운영 설정, DB·인덱스·가중치, 비공개 경로, 브라우저 프로필을 넣지 않았습니다. 원래 live 모델 실험 전체를 바로 재현하는 묶음이 아닙니다.
