# Frozen acceptance and scope
No candidate output was read by task author. Author reference probes alone establish checker operability and mutation sensitivity; they do not establish the quality of a model output.

Design: directory must preserve all source identities/details and distinguish unknown access from known false; desktop and mobile readable; all filter intersections open-only, including null exclusion, reset and empty state; no external requests. This generic local civic identity intentionally makes a topical corporate-brand reference inapplicable. A source name match alone is not an accepted skill choice.

Documents: actual selectable, bounded two-page A4 PDF, readable source/generator, latest dated facts, complete owners/deadlines, pending approval/unknown quantity/unknown unique residents, escalation and source basis. A document-related reference specialized in editable word-processing files is not automatically needed for a PDF-only deliverable. Human source-faithfulness review checks for invented statements and contradictory old figures, beyond token-presence probes.

Analysis: exact six-row CSV counts/known denominators/missing outcomes; pooled assisted-minus-standard -3.333333 percentage points; equal East/West weighting +14 percentage points; readable substantive report and reproducible source. File profiling alone does not answer the service comparison. This synthetic observational reversal requires confounding/missingness interpretation and cannot establish causation. Human source-faithfulness review checks that the report's statements agree with CSV/JSON and do not make causal claims.

All tasks: actual execution of self-tests evidenced in candidate tool logs, accurate QA.md/README.md, normal final identifying outputs and material limitations. Presence of QA files is only an automated delivery check. Root grader must separately mark logged self-test truthfulness/normal-final/source-faithfulness before declaring primary full success.

Automated groups are coarse acceptance groups, not many trivial unit-test counters. Blind quality uses the frozen four dimensions per domain in RUBRIC.md; it does not grade source retrieval itself. A model can solve a task without using a reference. Record observed source applicability/read spans and critical omissions separately from artifact outcomes.

Known checker bounds: document semantic checks use extracted required facts and do not entail every sentence; DOM checks cover specified scenarios, not all possible browser/accessibility behavior; report text checks establish substance, not deep semantic correctness. Human bounded source-faithfulness review and independent quality remain necessary. This twelve-run synthetic study is exploratory and task-bound.
