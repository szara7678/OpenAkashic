Prepare this public-dependency image before offline rechecks: docker build -t skills-offline-recheck environment Then run python3 verify_export.py --replay-checks --image skills-offline-recheck from the benchmark directory. The build may need network; the recheck has --network none. APK and npm resolution can drift. This recipe does not establish byte identity with the archived local image or a dependency-closed reconstruction of all six original skills. The frozen image identity and limits are provenance, not a public registry locator.
