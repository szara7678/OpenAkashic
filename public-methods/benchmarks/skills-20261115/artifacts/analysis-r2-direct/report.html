What changes the direction?

Among known outcomes, assisted exceeds standard in East by 8.0 percentage points (80.0% vs 72.0%) and in West by 20.0 points (60.0% vs 40.0%). Yet assisted has 50 of its 60 known outcomes in West, where success is lower for both services; standard has 50 of its 60 in East. This mix produces a Simpson’s-paradox reversal in the pooled comparison.

Equal-branch rates are (80.0% + 60.0%) / 2 = 70.0% for assisted and (72.0% + 40.0%) / 2 = 56.0% for standard. This is a hypothetical 50/50 branch mix, not the actual case-weighted performance or full case-mix adjustment.

Unknown is not failure

All 140 cases are included in the counts. There are 20 unknown outcomes (20/140 = 14.3% of all cases): 10/70 = 14.3% in each service. Equal overall missingness hides different branch patterns, notably standard West with 9/19 = 47.4% unknown. If outcome recording is related to success, both the pooled and equal-branch estimates may be biased. Blank outcomes are excluded only from success-rate denominators; none are imputed.

What the log can—and cannot—support

This observational log is not randomized. Branch weighting addresses only branch mix, not severity, routing, staff, timing, or other unrecorded differences. Outcome definitions and follow-up windows are not supplied beyond the resolved flag (1 = success, 0 = failure, blank = unknown). Small known-outcome cells and missing data limit stability and generalization; these descriptive differences do not establish causation or statistical significance.

Practical next step: Audit and recover unknown outcomes, prioritizing standard West, using a consistent outcome definition and follow-up window. Track success and missingness by branch. Before wider rollout, run a prospective, branch-stratified randomized pilot if feasible, with consistent case eligibility and severity capture.

Method: complete local log, one row per case; no row sampling, no imputation, no external resources. Differences are assisted minus standard; pp = percentage points.
