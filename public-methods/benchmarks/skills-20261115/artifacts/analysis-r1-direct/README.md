```sh

```

## Result
140 cases; 120 known outcomes; 20 unknown. Assisted has 38/60 successes (63.33% of known), standard 40/60 (66.67%). Pooled assisted-minus-standard difference: −3.3333 percentage points. Equal-branch rates: assisted 70%, standard 56%; difference +14 pp. Assisted leads in both branches; unequal branch mix reverses the pooled direction. Unknown outcomes are not failures and are never imputed.
