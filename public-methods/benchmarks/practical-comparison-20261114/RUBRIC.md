# Frozen evaluation gates

Executable acceptance is defined by checker.py and tasks.json. Independent blind quality review gives correctness, evidence_fit, limitations and artifact_usability each 0..2. Full success also requires every quality dimension >=1, no material unsupported claim and assigned retrieval compliance. The frozen scoring implementation additionally requires normal CLI completion; that gate is reported separately from artifact checks to expose resource-limit failures. All eight independent quality grades are included. Masking was imperfect: some README source-workflow descriptions revealed arm clues. The reviewer did not independently execute candidates; checker results are separate.

OA first search with no applicable result followed by ordinary web fallback is valid. Reading an unrelated method cannot be reported as applying it successfully. Method exposure, task completion, code correctness and causal utility are different observations.

The source snapshot, tasks and criteria were not revised after v4 outputs. The v4 budget/replication change was explicitly adaptive after v3 failures; v2/v3 remain separate negative cohorts.
