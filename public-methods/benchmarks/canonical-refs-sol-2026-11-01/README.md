# Sol-medium 모델 전환 검증

**사전 주 관문 PASS. 엄격 성공 direct 9/9, source 9/9.**

전체 토큰 394,907 → 117,358 (70.28% 감소), 성공당 토큰 43,878.56 → 13,039.78 (70.28% 감소). 평균 온라인 시간 30.57 → 19.61초.

Luna의 최소 성공 관문 실패를 관찰한 뒤 실용 메인 모델로 gpt-6.1-sol medium을 양쪽에 동일 적용한 전향적 모델 전환입니다. 새 독립 질문 9개, 기존과 같은 18개 출처이며 새로운 코퍼스 검증이 아닙니다. 엔진/계약을 답변에 맞춰 바꾸지 않았습니다. 미리 독립된 모든 모델/업무에서 성공을 입증한 비교가 아닙니다.

sol/은 최신 18회이고 preceding-luna/는 직전 Luna 실패 18회 및 그 이전 v3 실패 18회의 전체 아카이브입니다. [초기 45회 원본](https://github.com/szara7678/OpenAkashic/tree/main/public-methods/benchmarks/evidence-prefetch-2026-11-01)은 커밋 1ce70a54cf0ce639fd9519d9ca309f076efbcf5e 그대로 유지합니다. 99회 후보 비용은 앞선 81회 3,137,030 + 최신 512,265 = 3,649,295토큰입니다. 실패를 삭제하거나 코호트의 성공률을 합치지 않습니다.

`python verify_results.py`로 최신/보존 참조 코호트 54회의 제공자 영수증·raw/렌더링 대응·실제 노출 ID와 파일 해시를 확인합니다. 초기 45회는 고정 공개 묶음으로 링크합니다. v3/v4 검증기는 각 고정 빌드와 인덱스의 별도 프로세스로 동작합니다. 전체 원문 스냅샷/인증/로컬 경로는 제외합니다.

raw 사실 판정과 형식·ID·근거 워크플로 완료는 별도입니다. 권고·불확실성 총점은 각각 18점 만점이며 2/2 진단은 주 문턱을 바꾸지 않습니다. 기계 인용 검사는 의미적 참을 증명하지 않습니다. 후보/채점 모두 Sol 계열인 단일 반복 모델 평가이며 전문가 패널·현업 성과·실제 코드 실행·인터넷 전체 검색·그래프 고유 효과를 입증하지 않습니다.

캐시 입력을 제공자 토큰에 포함하고 실제 돈·준비·개발·수집/라이선스·채점/유지보수 비용은 미측정입니다. 문맥/호스트 최종 응답 비청구 토큰과 렌더링 시간은 별도로 공개합니다. 짧은 ID가 원문 전송량을 없앴다고 세지 않습니다.

보조 원시 카운터(캐시 입력 제외 입력+출력)는 151,835 → 100,846 (33.58% 감소)입니다. 가격을 적용하지 않은 합계이며 실제 돈 절감이 아닙니다.

공개물은 로컬 라이선스 파일 포인터를 제거하며 원본/공개 패킷 해시와 크기를 구분합니다. 원문 인용·canonical ID·출처 해시·범위·순위는 유지하고 API 공개 응답 토큰만 선택 후 다시 셉니다. 원래 실험 패킷/모델 사용량/점수는 그대로이며 낮아진 공개 표현 카운터를 관측 사용량에 소급 적용하지 않았습니다.

## 전체 기록과 검증

큰 원본 JSON은 [evidence-bundle.tar.gz](evidence-bundle.tar.gz)에 원래 파일 해시·중첩 검증기와 함께 담았습니다. 불리한 결과도 보존했습니다. 최신 요약·질문·판정 기준·사용량은 sol/에서 바로 읽을 수 있습니다. 초기45회 전체 원본은 고정 커밋 링크로 제공합니다.

Python3.12 이상에서 아래 명령은 아카이브 SHA-256을 확인하고 임시 폴더에 풀어 모든 기록의 집계와 영수증을 검증합니다. 모델 호출이나 인증은 필요하지 않습니다. 모델 실험을 새로 실행하거나 사람의 효용을 검증하는 명령은 아닙니다.

    python verify_results.py

직접 압축을 풀어 evidence-bundle/ 안의 검증기를 실행해도 됩니다.
