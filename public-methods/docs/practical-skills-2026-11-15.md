# 공개 스킬 선택 비교: 2026-11-15

이번 비교에서는 원본 스킬 6개를 이름·설명 카탈로그에서 찾아 읽는 경로와, 같은 원본에서 만든 OA 방법 10개를 먼저 검색하는 경로를 비교했습니다. 디자인, PDF 문서, 데이터 분석의 새 합성 과제 3개를 조건별 두 번 실행했습니다. 12회를 모두 분모에 남겼고 실패를 재시도하지 않았습니다.

직접 경로는 skills.sh 실시간 검색을 흉내 낸 것이 아닙니다. 고정된 오프라인 카탈로그와 같은 원본 폴더에서 필요한 부분을 점진적으로 읽는 기준선입니다. 두 조건 모두 원본과 참조 파일에 접근할 수 있었으며, gpt-6.1-sol medium, 새 HOME, 도구와 실행 자원 한도를 같게 했습니다. 사용자 업무나 일반적인 검색 성능을 대표하지 않는 소규모 탐색 비교입니다.

## 결과

엄격한 전체 성공은 직접 경로 2/6, OA 2/6입니다. 기계 검사 전 항목 통과, 실제 수행한 자기 검증의 정직한 기록, 출처 충실성, 정상 최종 응답과 차단 결함 부재를 함께 요구했습니다. 부모 검토자는 두 평가자의 원래 점수를 덮어쓰지 않았습니다.

공동 완전 성공은 분석 과제의 같은 두 짝뿐입니다. 이 집합 전체를 토큰과 시간 지표에 똑같이 사용했습니다. OA 제공자 총 토큰은 292,155, 직접 경로는 269,420으로 OA가 8.44% 더 많았습니다. 경과 시간은 354.673초와 367.410초로 OA가 3.47% 짧았습니다. 같은 두 짝의 보수적 품질 평균은 양쪽 모두 14/16이며 반복별 차이는 +1, −1입니다. 품질이 낮은 짝을 비용 계산에서 제외하지 않았습니다.

사전 실용 기준은 제공자 총 토큰 15% 이상 감소, 경과 시간 10% 이상 감소와 세 분야 품질 유지의 동시 충족이었습니다. 토큰은 증가했고 시간 차이도 기준보다 작았습니다. 디자인·문서에는 공동 완전 성공 짝이 없으므로 세 분야의 품질 유지를 판정할 수도 없습니다. **실용 기준을 충족하지 못했으며 효율 개선을 입증하지 못했습니다.**

실패를 포함한 전체 12회에서 직접 경로는 742,703토큰·956.738초, OA는 816,822토큰·1,015.863초였습니다. 제공자 총 토큰은 반복 입력과 출력을 포함합니다. 캐시 입력은 입력 토큰에 이미 포함되어 중복 합산하지 않았습니다. 청구 금액과 준비·수집·방법 편집·검토 비용은 측정하지 않았습니다.

## 원문 전달, 적용, 산출물의 구분

OA 여섯 실행 중 두 실행에는 같은 PDF 방법이 완전 전달됐지만 웹·분석 과제에 부적합하여 적용되지 않았습니다. 네 실행은 빈 결과였습니다. 확인한 OA 파생 방법 적용은 0회입니다. 이후 원본 스킬을 읽어 만든 산출물이나 분석 성공을 OA 방법 실행 성과로 귀속하지 않습니다. 해당 방법에 대한 실행 결과를 만들어 기록할 근거도 없습니다.

원문이 도구 stdout에 전달됐다는 사실은 모델이 전부 주의 깊게 읽었거나 시각 도구의 이미지를 보았다는 증거가 아닙니다. 시각적 주의 여부는 독립적으로 확인하지 못했습니다. 이를 보지 않았다는 단정으로 바꾸지도 않았습니다. 원문 단계, README 귀속, 구현과 검사 근거는 공개 묶음의 source-application-review.json에 구분해 남겼습니다.

원본은 anthropics/skills의 frontend-design, brand-guidelines, pdf, docx와 K-Dense-AI/scientific-agent-skills의 exploratory-data-analysis, statistical-analysis입니다. 각각 커밋 1780c5e5a552fd4d1c9d6a7b0cab26b0c2bef064, 2d2065fb4520fa3f3f2bcf61cff26ec8b7eba4b5에 고정했습니다. 원래 Apache-2.0/MIT 라이선스·고지와 파일 매니페스트를 보존합니다. [재구성 도구와 검증 경계](reconstruct-public-skills.md)는 별도이며, 원본 121개와 연결 의존성 전체가 바로 실행 가능한 닫힌 환경이라는 뜻은 아닙니다.

## 보존한 도구 실패와 검사 제한

첫 직접 디자인 실행은 12회 제공자 호출 한도에서 종료됐고 171,971토큰을 사용했습니다. 재시도하거나 전체 성공으로 바꾸지 않았습니다. 뒤이어 Chromium 프로필의 권한 때문에 원래 검사 복사가 중단됐습니다. 외부 제어 보정은 읽기 전용 원본에서 UID 65534로 복사하고 브라우저 프로필만 제외했습니다. 원본·복사 바이트, 원래 시간·추적·프롬프트 해시를 확인한 뒤 같은 고정 검사를 모든 행에 적용했습니다. 모델, 기준, 예산, 입력과 후보 산출물은 유지했습니다.

고정 문서 검사는 날짜를 ISO 문자열로 찾기 때문에 같은 날짜를 영문으로 적은 경우를 인정하지 못합니다. 디자인 검사의 Service 접두 선택자는 Services 컨테이너와 충돌할 수 있습니다. 이 한계를 공개하고 실패 결과를 그대로 보존했습니다. 원래 checker-v2 판정을 고치지 않았습니다. 독립 검토용 화면을 준비할 때만 정확한 combobox 선택자로 빠진 필터 상태를 보충했고 원래 렌더 실패와 해시도 보존했습니다.

두 독립 검토자는 익명 화면과 산출물을 검토했습니다. 항목별 낮은 점수를 합산했고 원점수와 반복별 변동을 공개합니다. 검색과 실제 검사가 섞인 명령에서는 부모가 승인한 출처 정체성 범위만 가리고 실제 코드·검사·출력은 유지했습니다. 기법·문체·자기 보고에 단서가 남을 수 있어 완전한 블라인딩을 보장하지 않습니다.

## 공개 자료와 재검사

[공개 묶음](../benchmarks/skills-20261115/README.md)은 과제·입력·동결된 루브릭·검사, 행별 비용·실패, 두 검토와 부모 판정, 원래 산출물·생성기·QA·README를 담습니다. 원본 UID 복사 영수증과 같은 바이트를 내보냈으며 네 CSV의 CRLF도 그대로입니다. 익명 패킷의 LF CSV를 원본으로 내보내지 않았습니다. 두 해시와 차이를 함께 기록했습니다.

verify_export.py는 먼저 매니페스트와 원본 바이트를 대조합니다. 선택적으로 네트워크 없는 읽기 전용 Docker 안에서 고정 검사를 다시 실행하며 실패도 기대 결과로 대조합니다. 후보 코드를 호스트에서 실행하지 않습니다. 공개 의존성 이미지 준비 예시는 원래 이미지 바이트나 전체 live 에이전트 실험의 즉시 재현 환경을 보장하지 않습니다. 인증, 원시 제공자 trace·시스템 프롬프트, 운영 설정, DB·인덱스·모델 가중치와 비공개 경로는 제외했습니다.

이 비교와 이후 공개 서비스의 원본 조회·인덱스·쓰기 차단 확인은 서로 다른 증거입니다. 서비스 연결 확인을 이번 검색의 관련성·사용성이나 브라우저 UX 검증으로 바꾸지 않습니다. 이전 11월 14일과 11월 15일 비교 자료는 보존했으며 이번 12회와 합산하지 않았습니다.
