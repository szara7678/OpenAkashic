# OpenAkashic

상황과 목적에 맞는 방법, 적용 조건, 실제 적용 보고와 정정을 연결하는 **공개 노하우 아카이브**입니다. 공개 문서는 방법을 뒷받침하는 근거로 사용합니다.

- [현재 서비스와 설치 안내](public-methods/README.md)
- [에이전트 HTTP API 사용법](public-methods/llms-install.md)
- [API 계약과 평가 한계](public-methods/docs/public-methods.md)
- [소유자 운영·백업·복구](public-methods/docs/knowhow-operations.md)
- [공개 아틀라스](https://knowledge.openakashic.com/)

공개 서비스는 익명 읽기·검색 전용이며 가입·공개 투고·리뷰·claim 승인 절차를 제공하지 않습니다. 소유자만 별도 비공개 API writer에 인증해 기록합니다. Closed Akashic의 개인 원문·기억은 별도 시스템입니다.

이 저장소의 현재 실행 가능한 노하우 서비스는 public-methods/에 있습니다. 이전 capsule/MCP, 일반 지식 그래프·뉴스·시간 관련 자료는 역사적 코드·평가 기록이며 현재 설치나 입력 경로가 아닙니다. 과거 결과를 현재 서비스의 정확도·비용 절감 증거로 해석하지 않습니다.

디자인·문서·데이터 분석의 공개 스킬 6종을 고정 커밋과 원본 파일 해시로 보존하고, 근거 구간이 연결된 방법 10개를 추가했습니다. [원본 복원과 사용법](public-methods/docs/reconstruct-public-skills.md), [원본 조회 API](public-methods/docs/public-skill-sources.md)를 제공합니다. 스킬이나 설치 스크립트를 서비스가 실행하지는 않습니다.

최근 [원본 스킬 직접 탐색과의 별도 12회 비교](public-methods/docs/practical-skills-2026-11-15.md)에서는 효율 개선을 입증하지 못했습니다. 실패를 포함한 전체 실행에서 OA는 제공자 총 토큰 약 10.0%, 경과 시간 약 6.2%를 더 썼습니다. OA 6건 중 파생 방법을 실제 적용한 사례는 0건이었고, 빈 검색 4건과 부적합 전달 2건 이후 원본 스킬을 참고했습니다. 원본 사용을 OA 방법의 효과로 집계하지 않습니다. 품질·검사 한계·실패·수정과 원점수를 함께 공개합니다.

앞선 별도 검증: [네 합성 과제의 16회 비교](public-methods/docs/practical-efficiency-2026-11-15.md). 양쪽이 모두 완전 성공한 같은 5짝에서 총 토큰은 14.26% 적었지만 시간 차이는 −0.535%로 사실상 같아, 명확한 속도 향상이나 일반적 효율 개선은 입증하지 못했습니다. [앞선 11월 14일의 부정적 결과](public-methods/docs/practical-comparison-2026-11-14.md)와 실패·누락도 별도로 보존합니다.
