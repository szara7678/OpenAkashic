# Historical MCP integration

The current service is a know-how-only HTTP/OpenAPI application. Start with
[the current agent guide](../public-methods/llms-install.md).
No public signup, contribution, review or claim-approval onboarding is provided.
Public reads need no key. Owner writes use a separate private API. Closed private
memory remains a separate service. Old registry recipes are inactive historical
material; do not infer public endpoint availability or run auto-provision flows.
[Archived original documentation](../docs/legacy/README.md).
