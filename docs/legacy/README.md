These inert .txt files preserve previous root agent/install/Core/MCP instructions
and registry metadata. They are not current instructions or executable installers.
Public signup, token provisioning, contribution, review and claim-approval flows
described in them are retired. Historical deployment paths in the Core README
were replaced with an external placeholder.

Use [the current know-how module](../../public-methods/README.md).
No evaluation artifact or benchmark result was removed or rewritten.
